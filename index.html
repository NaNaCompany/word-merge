Word 합치기

여러 DOCX 문서를 하나의 Word 파일로 합치세요. 문단·표·사진을 담은 문서를 원하는 순서로 이어 붙입니다.

    이렇게 사용하세요

    1. 합칠 문서를 두 개 이상 선택합니다.
    2. 위아래 버튼으로 파일 순서를 정합니다.
    3. 합치기를 누르고 완료된 파일을 저장합니다.

    일반 DOCX만 지원합니다. .doc, HWP, 암호·전자서명·변경 추적·메모·삽입 객체가 있는 파일은 Word에서 먼저 정리하세요.

    선택한 파일은 브라우저 안에서 처리합니다. 파일 본문과 이름을 서버로 전송하지 않습니다.

    • 문서별 구역·용지 크기 유지
    • 목록 번호·스타일 ID 충돌 처리

    원본은 그대로 둡니다

    입력 파일을 덮어쓰지 않습니다. 결과를 새 파일로 저장하고, 실제 제출·인쇄 전에 내용과 순서를 확인해 주세요. 문서 안의 글꼴은 파일을 여는 환경에 따라 다르게 보일 수 있습니다.

    기능 제한과 지원 범위는 아래 안내에서 확인할 수 있습니다.

    자주 묻는 질문

    옛날 Word .doc 파일도 되나요?

    DOCX 파일만 지원합니다. .doc 파일은 Microsoft Word나 LibreOffice에서 열어 .docx로 저장한 다음 선택해 주세요. 파일 확장자만 바꾸는 것은 변환이 아닙니다.

    문서 모양도 그대로 유지되나요?

    문단·표·이미지와 문서별 구역 설정을 복사합니다. 문서 경계는 다음 페이지에서 시작합니다. 전체 테마·기본 글꼴 환경과 일부 필드 계산은 첫 문서 또는 문서를 여는 Word 환경의 영향을 받으므로, 출력 전에 결과를 확인하세요.

    메모나 변경 추적이 있으면 어떻게 하나요?

    본문의 변경 내용 추적·메모·삽입 객체를 감지하면 합치기를 중단합니다. Word에서 변경 내용을 검토·확정하고 메모를 정리한 사본을 사용하세요. 이미지·링크가 있는 각주나 미주도 현재 지원하지 않습니다.

    문서는 서버에 저장되나요?

    선택한 문서의 본문과 파일은 서버에 업로드하지 않습니다. 페이지에서 사용 중인 브라우저의 메모리 안에서 처리하고, 결과를 직접 다운로드합니다. 페이지를 닫으면 선택 목록은 사라집니다.

    개인정보·이용 안내

    선택한 파일은 현재 브라우저에서 처리합니다. 이 앱은 파일이나 입력 내용을 저장하는 서버를 사용하지 않습니다. 접속 통계 및 광고를 위해 Google Analytics·Tag Manager·AdSense와 Cloudflare 분석 도구를 사용하며, 이들 서비스에는 일반적인 접속 정보가 전달될 수 있습니다. 파일 내용·이름·QR 입력값을 분석 이벤트로 보내지 않습니다.
